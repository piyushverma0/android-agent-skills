# ANDROID-SKILL Docs: Overview

ANDROID-SKILL is the website/documentation experience for `android-agent-skills`, an Android-first skills pack for AI coding agents.

## What it is

- A repository of reusable Android development skills.
- Skills are Markdown-first and designed for progressive disclosure loading.
- One install command powers all supported agents.

```bash
npx skills add piyushverma0/android-agent-skills
```

## Why it exists

Generic skill packs miss Android-specific constraints. ANDROID-SKILL focuses on:

- MVVM + UDF architecture
- Hilt-only dependency injection
- Coroutines + Flow (not LiveData/RxJava)
- Jetpack Compose production patterns
- Supabase Android auth/error patterns

## Key facts to show on docs landing

- 5 skills

- 3-level progressive disclosure
