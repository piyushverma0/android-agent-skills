# ANDROID-SKILL Docs: Contributing

This page is the website-facing contribution entrypoint.

## Start here

- Repository contribution guide: [`CONTRIBUTING.md`](../../../CONTRIBUTING.md)
- Core project overview: [`README.md`](../../../README.md)
- Authoritative contributor rules: [`AGENTS.md`](../../../AGENTS.md)

## Contribution workflow

1. Pick one scope (one skill or one docs track).
2. Make changes with clear rationale and examples.
3. Validate links and command snippets.
4. Open PR with concise summary + validation notes.

## Skill contribution checklist (high level)

- Keep valid YAML frontmatter.
- Ensure Common Mistakes section exists.
- Keep examples production-ready and Android-specific.
- Link reference files from SKILL.md where relevant.

## Website/docs contribution checklist

- Use copy-ready commands.
- Keep `/docs` and `/audit` links intact.
- Keep route references aligned with information architecture.
